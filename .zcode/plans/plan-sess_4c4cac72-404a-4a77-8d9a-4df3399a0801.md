# Decentralized Lottery — Full UI/UX Redesign

## Design philosophy

**Dieter Rams:** "Less, but better." One focal point per screen. One primary action per card. Honest, unobtrusive, self-explanatory.

**Edward Tufte:** Maximize data-ink ratio. Erase non-data ink. Progress bars instead of bare numbers. Status dots instead of label pills. Inline metadata instead of 2×2 grids.

**Goal-driven UI:** The game's emotional arc is **anticipation → commitment → suspense → reveal → reward**. The UI must serve each beat:
- Hero jackpot = anticipation (live-counting gold number)
- Buy ticket = commitment (frictionless, clear odds)
- Countdown = suspense (ticking, color-shifting when urgent)
- Slot-machine reveal = the climax (2.5s number roll → winner lands)
- Claim = reward (green success, balance update)

## Design system

### Color (dark gaming theme — forced, not prefers-color-scheme)
| Token | Value | Role |
|---|---|---|
| bg-base | `#0B0D12` | App background |
| bg-elevated | `#13161D` | Cards |
| bg-elevated-2 | `#1B1F29` | Hover/active |
| border-subtle | `rgba(255,255,255,0.06)` | Hairlines |
| text-primary | `#F5F7FA` | Headlines, prize numbers |
| text-secondary | `#9BA3AF` | Labels |
| text-muted | `#5C6470` | Addresses, timestamps |
| accent-gold | `#FFB020 → #FF8A00` gradient | Prize pool, winner |
| accent-green | `#14F195` (Solana) | Buy buttons, success |
| accent-danger | `#FF5470` | Errors, "lost", urgent countdown |
| accent-purple | `#9945FF` (Solana) | Links, secondary |

### Typography
- **Space Grotesk** (display): hero numbers, card titles — 700, tight tracking
- **Inter** (body): descriptions, labels — 400/500
- **Tabular figures** (`font-feature-settings: "tnum"`): all money/numbers so GSAP counters don't jitter width
- **JetBrains Mono**: addresses, tx signatures


No borders/shadows. Elevated dark surface + hairline. Lifts on hover (`translateY(-4px)`, `cubic-bezier(0.16,1,0.3,1)`, 0.3s). Status as colored dot, not pill.

## GSAP animation patterns

1. **Hero jackpot count-up** — proxy object tween, `power2.out`, 2s, fires on mount + when data refreshes
2. **Live countdown** — `useEffect` interval, `HH:MM:SS`, switches to danger red + pulse when <1h
3. **Winner reveal (slot machine)** — 2.5s: GSAP cycles random ticket numbers `repeat: 6`, then winner lands with `back.out(2)` scale bounce + canvas-confetti gold burst
4. **Card stagger entrance** — `y: 24, opacity: 0, stagger: 0.08, power2.out`
5. **Buy micro-interaction** — button shrink → progress bar overshoot → green checkmark fade
6. **Ambient orbs** — 2-3 blurred gold/green circles drifting slowly (`repeat: -1, yoyo`)
